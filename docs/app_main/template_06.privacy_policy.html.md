# Design of Template `privacy_policy.html`

## Rôle

Page publique d’information de politique de confidentialité (`/privacy-policy/`).

## Données Attendues

- `auth_mode`,
- `selected_group`.

## Contraintes Front

- contenu statique ou quasi statique,
- accessible sans authentification,
- rendu via le shell partagé pour cohérence navigation/thème.
